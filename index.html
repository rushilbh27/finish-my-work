AUTOMATION MATRIX

Choose your level of involvement.

Whether you want full human control over every answer or autonomous unattended completion across hundreds of questions.

Mode 1: Draft Only
Selects answers on page silently. Never hits submit. You review before handing in.
Mode 2: Full Submit
Solves the quiz, navigates the summary screen, confirms submission dialog, reaches review.
Mode 3: Course Batch
Queues and completes every assignment and quiz inside a specific course sequentially.
Mode 4: All Courses Sweep
Sweeps your entire LMS dashboard, skipping practice quizzes, completing only graded coursework.

INSTALLATION

Install in under two minutes.

It takes less than 120 seconds to load unpacked in any Chromium browser.

1

Clone the repository or download ZIP

Run the git command on the right, or download the ZIP archive from GitHub and extract it.

2

Open Chrome Extensions

Navigate to chrome://extensions in your browser address bar and enable Developer mode in the top-right corner.

3

Click Load Unpacked

Click the Load unpacked button and select the extracted extension directory.

4

Open Any Quiz & Hit Hotkey

Navigate to your quiz and press ⌘⇧S to solve the visible question, or ⌘⇧A for Auto-Pilot.
